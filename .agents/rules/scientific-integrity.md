# JALNETRA Scientific Integrity & Provenance Rule

1. **Explicit Data Classification**:
   Every numerical figure displayed in the UI or emitted by an API must be explicitly labeled as one of:
   - `MEASURED`: Directly acquired from physical telemetry, rain gauges, or ground sensors.
   - `SIMULATED`: Generated by a deterministic hydrological solver or physics-informed model.
   - `PREDICTED`: Inferred by a machine learning surrogate or numerical weather forecast.
   - `ASSUMED`: Engineering baseline parameter (e.g., standard KMC runoff coefficient = 0.85).

2. **Zero Fabrication**:
   - Never fabricate or hardcode fake water savings, avoided rupees in crores, or spared citizens counts.
   - If real sensor feeds or models are offline, fall back to clearly flagged synthetic demonstration baselines labeled as `SIMULATED / CALIBRATED BENCHMARK`.

3. **Physical Conservation Laws**:
   - Hydrological mass balance must close:
     $\text{Inflow} - \text{Outflow} = \Delta \text{Storage}$
   - Tank storage must never be negative ($S \ge 0$) and can never exceed physical tank capacity ($S \le C$).
   - Runoff cannot be negative ($Q \ge 0$).
